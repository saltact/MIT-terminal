		Figure 3.4: Using bisection search to approximate square root
```python
x = 25;
epsilon = 0.01;
numGuesses = 0;
low = 0.0;
high = max(1.0, x);
ans = (high + low)/2.0;
while abs (ans**2 - x) >= epsilon:
	print('low =', low, 'high =', high, 'ans =', ans);
	numGuesses += 1;
	if ans**2 < x:
		low = ans;
	else:
		high = ans;
	ans = (high + low)/2.0;
print('numGuesses = ', numGuesses);
print(ans, 'is close to square root of', x);
```
